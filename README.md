# Cell Biology

Interactive cell biology explorer with animal, plant, and prokaryote diagrams

**Live:** https://cell-biology.freeappstore.online

A free app on [FreeAppStore](https://freeappstore.online). App id: `cell-biology`.

## Develop

```bash
pnpm install
pnpm dev
pnpm build
pnpm run typecheck
pnpm test
```

Before publishing, run `fas check` (`npm i -g @freeappstore/cli`). Pushing to `main` deploys the app.
